# Code of Conduct - Zasady postępowania

1. Cel kodeksu <br> Celem kodeksu jest zapewnienie profesjonalnego i opartego na wzajemnym szacunku środowiska współpracy przy rozwijaniu projektu

2. Zasady współpracy <br> Każdy uczestnik projektu zobowiązuje się do:
-Traktowania pozostałych członków zespołu z szacunkiem.
-Uczciwej i aktywnej współpracy.
-Terminowego wykonywania powierzonych zadań.
-Informowania o problemach i opóźnieniach.
-Przestrzegania ustalonych zasad projektu.

4. Niedopuszczalne zachowania
-Obrażania i dyskryminowania innych osób.
-Celowego utrudniania pracy zespołu.
-Publikowania cudzych danych bez zgody.
-Wprowadzania zmian bez uzasadnienia i wiedzy zespołu.
-Niszczenia lub celowego uszkadzania projektu.

5. Code review
Każdy Pull Request powinien zostać sprawdzony przez innego członka zespołu.
Zgłaszamy błędy i proponujemy poprawki w konstruktywny sposób.
Autor Pull Requesta powinien uwzględnić otrzymane uwagi.
Nie łączymy zmian przed ich zaakceptowaniem.

6. Zgłaszanie naruszeń
-Naruszenia zasad należy zgłaszać osobie odpowiedzialnej za projekt.
-Zgłoszenie powinno zawierać krótki opis sytuacji.
-Każde zgłoszenie powinno zostać rozpatrzone z zachowaniem poufności.

7. Konsekwencje naruszeń
W zależności od sytuacji mogą zostać zastosowane:

-Upomnienie.
-Ostrzeżenie.
-Czasowe ograniczenie udziału w projekcie.
-Usunięcie z projektu w przypadku poważnych lub powtarzających się naruszeń.

**Współpraca, wzajemny szacunek i odpowiedzialność za własną pracę są podstawą rozwoju tego projektu**.
